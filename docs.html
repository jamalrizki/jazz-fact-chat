How it works

Tools, tool calls, and the MCP server behind Jazz Fact Chat.

The short version

Jazz Fact Chat is a chat app backed by a free open-weight model (gpt-oss-120b on Groq, with OpenRouter's free models as a fallback). On its own, the model will confidently make up who played on a record. So it is given tools: small functions that fetch real data from Wikipedia, All About Jazz, MusicBrainz, a curated fact list, and a library of chord charts. The model answers well-known things directly and looks up anything it isn't sure of.

The same tools are also published as an MCP server, so any MCP client (Claude, an IDE, the MCP Inspector) can use them directly, without this website.

What happens when you ask a question

  1. Browser → Worker Your question, plus the conversation so far, goes to a Cloudflare Worker. The API keys live there as secrets and never reach your browser.
  2. Worker ↔ MCP server The Worker acts as an MCP host. It runs initialize, then tools/list, to learn which tools exist and what arguments they take.
  3. Worker → model It sends the model your conversation and the tool definitions (names, descriptions, JSON Schemas). The model never sees the tool code.
  4. Model → Worker The model either answers directly, or replies with a tool call such as album_lineup({"album": "Kind of Blue", "artist": "Miles Davis"}). It cannot run anything itself.
  5. Worker → tool → model The Worker runs the tool via MCP tools/call and sends the result back to the model. Steps 4–5 repeat (at most 4 rounds) until the model answers in plain text.
  6. Worker → browser You get the answer plus a trace of every tool call. Expand "Used N tools" under any answer to see the exact arguments and raw results.

When the model calls which tool

The model picks a tool by reading its description, so the descriptions are written as instructions. In practice:

  • "Who played drums on Kind of Blue?" → album_lineup. Any question about personnel or release year. The description says never to answer these from memory.
  • "Who was Mary Lou Williams?" → lookup_musician. Biography, dates, instruments, career.
  • "How many albums did Miles Davis make with John Coltrane?" → search_jazz. The general fallback: it searches Wikipedia (plus All About Jazz, Discogs and the Jazz Discography Project when configured) and returns only the passages relevant to the question. The model uses it whenever it isn't sure, and whenever another tool comes back empty.
  • "Tell me a fun jazz fact." → random_jazz_fact. Only for trivia requests, never to answer a specific question.
  • "Chords for Autumn Leaves in E minor." → chord_chart. Changes come from a curated library and are transposed in code, not by the model, because transposition is exact arithmetic that models often get wrong. For tunes outside the library, the model says so and suggests ones it has. It doesn't guess, because a confident-looking wrong chart is worse than none.
  • "What's a ii–V–I?" → no tool. General theory is something the model knows well enough.

If a tool finds nothing, the model is instructed to say so instead of filling the gap from memory. Ask about an obscure record and you'll usually get "MusicBrainz doesn't list the personnel" rather than invented names.

Use the MCP server directly

Endpoint: …/mcp

  • Transport: Streamable HTTP, stateless. Each JSON-RPC message is one POST; responses are plain JSON.
  • Methods: initialize, ping, tools/list, tools/call.
  • Capabilities: tools only (no resources or prompts). No authentication. All tools are read-only.

List the tools from a terminal:

curl -s …/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Or connect a client: in the MCP Inspector, choose Streamable HTTP and paste the endpoint URL. In Claude, add it as a custom connector.

Honest limits

  • The model is free and open-weight. Tools make it far more accurate, but it can still misread a result or skip a tool call. Check the tool trace.
  • MusicBrainz is community-edited. Plenty of jazz records have no personnel credits there, and the app will tell you so.
  • Free tiers are rate-limited. If Groq is busy, OpenRouter answers instead (the footer shows which one did).

Security notes

  • API keys are Cloudflare Worker secrets. They are not in the page or the repository.
  • The chat endpoint only accepts requests from this site's origin. The browser can send only user and assistant messages, so it can't override the system prompt or forge a tool result.
  • Tool arguments come from the model, so they're validated and URL-encoded before any request goes out. Results are size-capped.
